# 💕 Интерактивная Валентинка

Романтичная интерактивная валентинка на День Святого Валентина с убегающей кнопкой "Нет" 😄

## ✨ Особенности

- 💖 Красивое романтичное оформление с анимированными сердечками
- 🎯 Кнопка "Да" для положительного ответа
- 🏃‍♀️ Кнопка "Нет", которая убегает от курсора мыши
- 🎉 Праздничная анимация при положительном ответе
- 📱 Адаптивный дизайн для мобильных устройств

## 🚀 Как запустить локально

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ваш-username/my-love.git
cd my-love
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект:
```bash
npm run dev
```

4. Откройте http://localhost:5173 в браузере

## 📦 Сборка проекта

Для создания production-сборки:
```bash
npm run build
```

## 🌐 Деплой на GitHub Pages

1. Убедитесь, что в `vite.config.ts` указано правильное название вашего репозитория в поле `base`
2. Запустите деплой:
```bash
npm run deploy
```

Ваша валентинка будет доступна по адресу: `https://ваш-username.github.io/my-love/`

## 🛠️ Технологии

- ⚛️ React 19
- 📘 TypeScript  
- ⚡ Vite
- 🎨 CSS3 с анимациями
- 📱 Адаптивный дизайн

## 💝 Как использовать

1. Откройте сайт
2. Прочитайте вопрос "Будешь моей валентинкой?"
3. Попробуйте нажать на кнопки:
   - ✅ "Да" - покажет праздничное сообщение
   - ❌ "Нет" - будет убегать от курсора 😉

## 🎨 Кастомизация

Вы можете легко изменить:
- Текст вопроса в `src/App.tsx`
- Цвета и стили в `src/App.css`
- Количество и позиции сердечек
- Анимации и эффекты
